# Project instructions

- Keep the first milestone limited to typing-triggered screenshots, local ML Kit OCR, and a development screen.
- Do not add cloud analysis, scam judgments, or voice without a new request.
- Never log or commit captured private text, screenshots, credentials, or local SDK paths.
- Respect Android secure windows and sensitive fields.
- Keep `isAccessibilityTool=false` unless the actual product purpose and applicable review support a change.
- Use the separate fixture for reproducible tests.
- Run the build, unit tests, and Android lint after relevant changes. Verify capture changes on an emulator or device.
- Use plain words and short active sentences in explanations.
